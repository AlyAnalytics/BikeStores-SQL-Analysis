# BikeStores Database Analysis 🚴‍♂️

## Overview
This project contains SQL queries used to analyze the BikeStores sample database. It was completed as part of the Data Analysis training program with the National Telecommunication Institute (NTI). The goal was to extract actionable insights regarding sales, inventory, and customer behavior.

## Skills & Tools Used
* **Database Management:** SQL Server Management Studio (SSMS)
* **SQL Concepts:** JOINs, Aggregations (`SUM`, `COUNT`, `MAX`), Filtering, Subqueries, Date Functions.

## Key Business Questions Answered
* What is the total revenue generated per store?
* Which product categories and brands are the most popular among customers?
* How many total customers does the business have, including those with rejected orders?
* Who are the top-performing staff members?

## Files in this Repository
* BikeStore Query.sql: Contains the solutions to the business questions.
* PDFs: Documentation of the query outputs and results.
